# Task 33 — Load test to find the ceiling

**Domain:** testing

## Scenario

A driver app must survive a launch spike. Design a load-test plan: realistic workload, measurement points, soak latency, naming the bottleneck.

## What a good answer contains (pass-bars)

Realistic workload; p95/soak measurement; bottleneck identification; no unverifiable '10k rps' claims.

Apply `rubric.md` (dimensions D1–D6). Expected activation path: `testing/load-performance -> performance/latency-optimization`.
